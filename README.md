# ChambaYa · demo

Demo de ChambaYa para probar en el teléfono y en la PC.

**Abrir:** https://spartan1714.github.io/chambaya-demo/

- Los datos son **de prueba** y se comparten entre todos los que abren la demo (se guardan en Supabase).
- No escribas datos reales: cualquiera con el link puede verlos.
- "Restablecer datos de ejemplo" vuelve a los datos iniciales para todos.

Este repo solo tiene la página de la demo. El código de la app está en un repo privado.
